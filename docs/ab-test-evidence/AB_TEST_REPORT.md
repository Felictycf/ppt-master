## 3. 汇总结论

1. **图标落地总体**：v4 平均 89/份 vs v210 平均 56/份 = **v4 为 1.6 倍**（T1 2.6 倍、T2 1.6 倍、T3 因 editorial 简约风 0.6 倍）。图标密度受视觉风格影响（v4-T3 的 editorial 杂志风本身克制）。
2. **风格一致性**：v4 字体族 1-2 族 vs v210 2-3 族——v4+补丁（P1 定频 lock 重读）在风格统一上全面胜出。
3. **质量门**：v210-T3 达 0 error / 0 warning（最佳）；v4-T1/T2 原始产物带 typography/溢出等 error，经人工修复后 0 error——**v2.10 检查契约更宽松**（生成即过），v4 检查更严格（需修复才过）。
4. **无人值守能力**：v4 有 Quick Generate 模式（模型自动路由）；v2.10 无此模式但 no-wait prompt 下可全流程自动完成。

## 4. 过程发现（证据详见 guardian-events.log）

1. glm-5.2 无人值守间歇"启动即冻结"（4 次复现）；deepseek-v4-flash 全程稳定（0 冻结）

4. v4-T3 展示"部分运行续接"能力；v210-T2 展示越界图标自纠能力
